# Qualia

> Qualia (Qualia Labs, Inc.) is a digital real estate closing platform. Its cloud-based title, escrow and settlement software brings title agents, lenders, real estate agents and consumers onto one secure system of record. The Qualia API, launched in August 2022, is a read-write GraphQL interface that lets proptech companies, lenders and enterprise title operations place and track title orders, exchange messages and documents, and pull order, accounting and contact data for custom reporting and executive dashboards.

Generated by the API Evangelist enrichment pipeline from the Qualia public surface. Qualia does not publish its own /llms.txt (probed 2026-08-02: 404 on www.qualia.com, qualia.com and learn.qualia.com).

### How it works

- Protocol: GraphQL over HTTPS. POST JSON to https://api.qualia.com/graphql.
- Authentication: HTTP Basic. The credential identifies the organization calling Qualia. There is no public self-service key provisioning — credentials are issued by Qualia.
- Authorization: capability gates. Calls are grouped by objective (placing orders, messaging, documents, reporting) and each gate must be enabled on the calling organization. Gates can be granted to or revoked from owned and partner organizations so data can be retrieved on behalf of the end consumer.
- Errors: the GraphQL errors array, with a machine code at errors[].extensions.code. An unauthenticated call returns HTTP 401 with code UNAUTHORIZED.
- Rate limiting: enforced for system stability; specific limits and headers are not published.
- Schema introspection is auth-gated (401 without credentials), so no SDL is published here.

### Documented capabilities

- Place title orders into Qualia Core/Connect, or route them to third-party systems
- Track title order status and pipeline across clients and settlement agency branches
- Send and receive messages on an order
- Send and receive documents on an order
- Pull order, accounting and contact data for custom reporting, notifications and dashboards

## Products

- Atlas: enterprise title and escrow system
- Resware: customizable title production platform
